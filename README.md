# Nexus SaaS Platform

## Project Description
A secure, multi-tenant SaaS application built with React, Node.js, and PostgreSQL. It features strict data isolation, JWT authentication, and automated cloud deployment.

## Features
- **Multi-Tenancy:** logical isolation for different organizations.
- **Authentication:** Secure JWT login with role-based access control.
- **CI/CD:** Automated deployment via Docker and Render.
- **Infrastructure as Code:** Managed via render.yaml.

## Tech Stack
- **Frontend:** React, Vite, TailwindCSS
- **Backend:** Node.js, Express
- **Database:** PostgreSQL
- **DevOps:** Docker, Render

## Setup Instructions
1. Clone the repo.
2. Run `npm install` in both frontend and backend folders.
3. Set up `.env` file with database credentials.
4. Run `docker-compose up` to start locally.
